# Market Signals Lab

Market Signals Lab is a learning-focused data and MLOps project for exploring stock market data, investing fundamentals, and model-serving workflows.

I am building this project to strengthen my understanding of financial markets while also practicing practical software, data, and cloud engineering skills.

This project is not financial advice, not a trading bot, and not intended to predict markets for real-money decisions. The goal is to learn responsibly, document my thinking, and build a professional technical portfolio project.

## Why I am building this

I wanted a project that connects several areas I care about:

- software engineering
- data engineering
- machine learning
- MLOps
- cloud deployment
- investing literacy
- responsible decision-making

Instead of treating the stock market like a quick-profit system, this project focuses on understanding market data, risk, diversification, model limitations, and how financial signals can be analyzed carefully.

## Project goals

- Learn stock market and investing fundamentals
- Understand ETFs, stocks, returns, volatility, and risk
- Build a reproducible market data pipeline
- Create baseline machine learning models
- Serve model outputs through an API
- Track model versions and prediction logs
- Document limitations and responsible interpretation
- Practice Docker, CI/CD, and cloud deployment over time
